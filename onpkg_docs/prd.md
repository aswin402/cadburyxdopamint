# PRD — Cadbury × Dopamint "Talk to Santa" Landing Page

## 1. Overview

**Product Name:** Cadbury × Dopamint — Talk to Santa  
**Type:** Promotional landing page (single-page marketing site)  
**Purpose:** A Christmas-themed campaign landing page for Cadbury's "Talk to Santa" AI-powered conversational experience, in partnership with Dopamint.  
**Target Audience:** Cadbury consumers (families, young adults, chocolate enthusiasts) looking for a festive, interactive holiday experience.

---

## 2. Goals & Objectives

| Goal | Metric |
|------|--------|
| Drive users to the "Talk to Santa" conversation experience | CTA click-through rate |
| Educate users on how the experience works (3-step process) | Scroll depth & section engagement |
| Build brand warmth and festive association with Cadbury | Time on page, social shares |
| Communicate the prize/competition opportunity | Banner visibility & CTA engagement |
| Ensure premium brand perception | Visual quality, load performance |

---

## 4. Responsive Requirements

| Breakpoint | Layout Changes |
|-----------|---------------|
| **Desktop** (≥1200px) | Full two-column hero, three cards in a row, full banner layout |
| **Tablet** (768px–1199px) | Hero stacks partially, cards may go 2+1 or remain 3 across (smaller), banner adjusts |
| **Mobile** (≤767px) | Single column throughout, hamburger nav, stacked cards, simplified banner, full-width buttons |

### Key Responsive Behaviors
- Navbar collapses to hamburger menu on mobile
- Hero image stacks below hero text on mobile
- Step cards stack vertically on mobile
- Feature cards stack vertically on mobile
- Prize banner stacks vertically (image → text → ornament) on mobile
- Footer illustration maintains aspect ratio, may crop on sides
- All text sizes scale down proportionally
- CTAs become full-width on mobile
- Golden arch around Santa image scales or simplifies on mobile

## 5. Content & Copy

All text content is defined in the section descriptions above. Key copy principles:
- **Warm, inviting, festive tone** — feels like an invitation, not an advertisement
- **Conversational language** — uses contractions, casual phrasing
- **Brand voice:** Cadbury's warm, joyful personality combined with Dopamint's tech credibility
- **Privacy messaging** is upfront and reassuring

## 8. Technical Requirements

- **Static HTML/CSS/JS** — No backend required for this landing page
- **Performance:** < 3s LCP, optimized images (WebP with fallbacks)
- **Accessibility:** Semantic HTML, alt text on all images, keyboard navigable, sufficient color contrast
- **SEO:** Proper meta tags, Open Graph tags, single H1, structured heading hierarchy
- **Browser support:** Chrome, Firefox, Safari, Edge (latest 2 versions)
- **No JavaScript frameworks required** — vanilla JS for interactions and animations
